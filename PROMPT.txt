# PROMPT MESTRE — PLATAFORMA DIGITAL DE VENDAS, CRM, WHATSAPP, IA E AUTOMAÇÕES COM ODVIX + MERCOS + N8N

## 1. PAPEL

Você é um arquiteto de software e desenvolvedor full-stack sênior responsável por projetar e implementar uma plataforma comercial completa para uma distribuidora/fabricante de produtos de limpeza.

O sistema não deve ser apenas um CRM ou chatbot.

O objetivo é criar um **Sistema Operacional de Vendas Digitais**, capaz de:

* identificar clientes que precisam comprar;
* identificar clientes em risco de perder;
* identificar oportunidades de recompra;
* encontrar leads;
* conversar automaticamente pelo WhatsApp;
* recomendar produtos;
* montar pedidos;
* recuperar vendas perdidas;
* executar campanhas;
* encaminhar negociações complexas para um representante;
* sincronizar tudo com o ERP ODVIX;
* integrar dados do Mercos;
* utilizar IA;
* executar automações através do n8n;
* gerar inteligência comercial;
* reduzir drasticamente a dependência de vendedores externos.

O fluxo principal deve ser:

DIGITAL → IDENTIFICAÇÃO → WHATSAPP → IA → NECESSIDADE → RECOMENDAÇÃO → CARRINHO → PEDIDO → ERP → PÓS-VENDA → RECOMPRA

O representante humano deve entrar somente quando sua intervenção aumentar a probabilidade de fechamento ou for necessária.

# 2. REGRA ARQUITETURAL MAIS IMPORTANTE

## N8N NÃO É O CORE DO SISTEMA

O n8n deve ser utilizado como:

* motor de workflows;
* automação;
* orquestração;
* integração;
* campanhas;
* notificações;
* processos assíncronos;
* automações de IA;
* follow-ups;
* processamento de eventos.

Porém, o n8n NÃO deve ser o proprietário das regras críticas do negócio.

A aplicação principal continua sendo a fonte de verdade para:

* clientes;
* produtos;
* preços;
* estoque;
* pedidos;
* condições comerciais;
* usuários;
* permissões;
* vendedores/representantes;
* CRM;
* leads;
* histórico;
* regras comerciais;
* integrações;
* auditoria.

Nunca implementar uma regra crítica exclusivamente dentro de um workflow n8n.
