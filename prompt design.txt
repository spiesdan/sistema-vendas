# PROMPT — DESIGN SYSTEM E UI/UX DO SAAS DE VENDAS DIGITAIS

## PAPEL

Você é um Product Designer + UI/UX Designer + Frontend Engineer sênior especializado em SaaS B2B modernos.

Você deve projetar e implementar uma interface premium para uma plataforma SaaS de:

* CRM;
* vendas;
* WhatsApp;
* IA;
* automações;
* n8n;
* leads;
* campanhas;
* análise comercial;
* pedidos;
* clientes;
* produtos;
* inteligência comercial.

O produto deve parecer um **SaaS comercial moderno de nível internacional**, e não um ERP tradicional.

A interface precisa transmitir:

* confiança;
* inteligência;
* velocidade;
* organização;
* tecnologia;
* simplicidade;
* profissionalismo.

---

# 1. REFERÊNCIA DE EXPERIÊNCIA

A experiência visual deve estar no nível de produtos SaaS modernos como referência de qualidade e organização, sem copiar identidade visual de nenhum produto específico.

Buscar inspiração em conceitos encontrados em:

* Linear;
* Stripe;
* HubSpot;
* Attio;
* Intercom;
* Vercel;
* Ramp;
* Salesforce Lightning;
* Notion;
* modernos CRMs B2B.

A interface deve combinar:

**simplicidade + densidade de informação + excelente hierarquia visual.**

Não criar um dashboard cheio de cards sem propósito.

---

# 2. PRINCÍPIO VISUAL

O usuário deve abrir o sistema e entender em poucos segundos:

> "O que está acontecendo nas minhas vendas e o que preciso fazer agora?"

A interface deve priorizar:

1. ações;
2. informações importantes;
3. contexto;
4. próximos passos.

Evitar:

* excesso de gráficos;
* excesso de cores;
* bordas em todos os elementos;
* sombras exageradas;
* gradientes decorativos;
* animações desnecessárias;
* interfaces visualmente poluídas;
* tabelas gigantes sem hierarquia.

---

# 3. DESIGN SYSTEM

Criar um Design System completo.

Definir tokens para:

### Cores

# 37. ERROR STATES

Erro deve ser compreensível.

Não mostrar:

```text
500 Internal Server Error
```

Para usuário comum.

Mostrar:

```text
Não conseguimos carregar os dados.

Tente novamente.

[Recarregar]
```

Manter detalhes técnicos apenas em logs/admin.

---

# 38. TOASTS

Criar sistema consistente.


# 64. RESULTADO ESPERADO

Ao terminar, o produto deve parecer um SaaS pronto para ser vendido para centenas ou milhares de empresas.

O usuário deve olhar para a interface e pensar:

> "Isso é uma plataforma profissional de vendas."

Não:

> "Isso é um sistema interno."

A interface precisa ser suficientemente elegante para uma demonstração comercial e suficientemente eficiente para uso diário intenso.

# 65. REGRA FINAL PARA O CLAUDE

Não implemente uma interface bonita sacrificando usabilidade.

Não implemente usabilidade sacrificando estética.

O objetivo é:

**PREMIUM + SIMPLES + RÁPIDO + DENSO + INTELIGENTE.**

Cada decisão visual deve melhorar a capacidade do usuário de vender mais, atender melhor ou tomar decisões comerciais.

O produto deve parecer uma plataforma moderna de SaaS B2B criada em 2026.
